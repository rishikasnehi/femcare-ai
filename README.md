
# FemCare AI

FemCare AI is a women's health education chatbot
focused on menstrual health, PCOS/PCOD, breast
health, mood changes, and weight-related concerns.

## Technology Stack

- Python
- FastAPI
- Google Gemini API
- React (planned frontend)

## Project Status

Backend initialization in progress.

## Scope

FemCare AI provides general women's health education.
It does not diagnose medical conditions or replace
professional medical advice.
